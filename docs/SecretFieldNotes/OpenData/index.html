地名データ(OpenStreetMap)

秘密のフィールドノート(以下「本アプリ」)

本アプリの地名検索は、端末に同梱した地名辞書を使って行います。この辞書は OpenStreetMap のデータから駅・山・集落の名称と座標だけを抽出した派生データベースで、Open Database License (ODbL) 1.0 のもとで、ここで公開しています。

地名データ:© OpenStreetMap contributors

ファイル

  • gazetteer.tsv.gz — 地名辞書(本アプリに同梱しているものと同一)
  • LICENSE.txt — 出典とライセンス
  • osm_places.py — 生成スクリプト(pyosmium)
  • build_gazetteer.dart — 生成スクリプト(osmium-tool の出力を畳む Dart 版)

形式

gzip 圧縮した UTF-8 の TSV です。# で始まる行はライセンス表記のヘッダです。

名前 <TAB> よみ <TAB> 緯度 <TAB> 経度 <TAB> 種別

種別は s=駅 / p=山 / t=集落。よみは OpenStreetMap に登録が無い場合は空欄です。

生成手順

Geofabrik の日本抽出から、次のどちらかで同じ辞書を生成できます。

curl -L -O https://download.geofabrik.de/asia/japan-latest.osm.pbf

# A: pyosmium だけで生成(pip install osmium)
python3 osm_places.py japan-latest.osm.pbf gazetteer.tsv.gz

# B: osmium-tool + Dart
osmium tags-filter japan-latest.osm.pbf \
  n/railway=station,halt n/natural=peak n/place=city,town,village,suburb \
  -o places.osm.pbf
osmium export places.osm.pbf -f geojsonseq -o places.geojsonseq
dart run build_gazetteer.dart places.geojsonseq gazetteer.tsv.gz

B の Dart スクリプトは archive パッケージを使うため、dart pub add archive を行った Dart プロジェクト内で実行してください。A と B は同じ辞書を出力します。

OpenStreetMap のデータは日々更新されるため、同じ手順でも生成した時期によって内容は変わります。
