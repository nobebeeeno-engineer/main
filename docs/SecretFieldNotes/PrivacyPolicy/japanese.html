プライバシーポリシー

秘密のフィールドノート(以下「本アプリ」)

かんたんに言うと

  • 本アプリはサーバーを持ちません。記録した場所・写真・メモは、すべてお使いの端末の中だけに保存されます
  • 利用者の明示的な操作なく送信されるデータは一切ありません
  • 外部との通信は「地図・標高データのダウンロード」と「購入・購入復元時のストア決済」の2つだけです
  • 写真に含まれる位置情報(EXIF)は、取り込んだ時点で削除します
  • 利用状況の分析、広告、クラッシュレポートの自動送信は一切行いません
  • ただし、端末のOSが行う自動バックアップ(iCloud / Android バックアップ)には、記録と写真が含まれます

以下が正式な内容です。

1. 基本方針

RikuoNobe(以下「当方」)は、本アプリの提供にあたり、利用者のプライバシーを最大限に尊重します。

本アプリは、利用者の記録を預かるサーバーを持ちません。採取ポイントの座標、写真、メモ、日時などの記録データは、すべて利用者の端末内に保存され、当方がこれを取得・保有することはありません。

本アプリには、利用者の明示的な操作なく送信されるデータは一切ありません。

2-1. 位置情報について

位置情報は、記録を保存する瞬間と、現在地ボタンを押した瞬間にだけ取得します。バックグラウンドでの位置情報の取得、および移動の軌跡の記録・保存は行いません。本アプリは「常に許可」の位置情報権限を要求しません。

2-2. 写真について

本アプリは、取り込んだ写真からEXIF(撮影日時・位置情報・機種情報などのメタデータ)をすべて削除したうえで保存します。撮影日時のみを読み取って端末内のデータベースに保持しますが、写真ファイル自体には残しません。この処理は、カメラで撮影した場合と写真ライブラリから選んだ場合のどちらの経路でも必ず適用されます。

写真は長辺1600ピクセルに縮小して再保存し、端末内のアプリ専用領域に置きます。端末の写真ライブラリに書き戻すことはありません。

2-3. 生体認証・パスコードについて

生体認証(Face ID / Touch ID / 指紋認証)は、端末のOSが認証の成否のみを返す仕組みです。指紋や顔のデータを本アプリが受け取ることはありません。

補助のパスコード(6桁)は、平文では保存しません。端末固有の値を加えたうえでハッシュ化(PBKDF2-HMAC-SHA256)し、端末内の安全な保管領域(iOS: キーチェーン / Android: 暗号化された保管領域)に保存します。この情報は端末の外に出ず、後述のOS自動バックアップにも含まれません。

3. 本アプリが取得しない情報

本アプリは、以下の情報を取得しません。取得するための機能やライブラリを組み込んでいません。

  • 氏名、メールアドレス、電話番号その他の連絡先情報(アプリ内でのアカウント登録は存在しません)
  • 端末の識別子、広告識別子(IDFA / AAID)
  • 端末の連絡先、カレンダー、通話履歴
  • マイク、音声
  • 利用状況の統計、操作ログ、画面の閲覧履歴

4. データの保存場所

記録データ(採取ポイント、記録、品目、エリア情報)は端末内のデータベースに、写真は端末内のアプリ専用領域に保存されます。当方はこれらを保有せず、参照することもできません。

5. 外部との通信

本アプリが外部と通信するのは、次の2つの場合だけです。いずれの通信にも、記録データ(座標・写真・メモ)は含まれません。

5-1. 地図・標高データのダウンロード

利用者が地図の表示・ダウンロードを行うとき、国土地理院が提供する地理院タイル(cyberjapandata.gsi.go.jp)へ接続し、地図画像および標高データを取得します。

このとき送信されるのは、必要な地図の区画を示す座標と、本アプリを識別するための文字列だけです。利用者の識別子やCookieは送信しません。

5-2. 購入・購入復元時のストア決済

買い切りの購入、および購入の復元を行うとき、App Store / Google Play と通信します。決済はストアが行い、当方はクレジットカード情報などの決済情報を取得しません。

5-3. 地名検索について

地名の検索は、アプリにあらかじめ同梱されたデータを使用します。検索のために外部へ通信することはありません。

6. 正直にお伝えすること

本アプリは端末内で完結する設計ですが、次の点については、記録が端末の外に出る可能性があります。隠さずにお伝えします。

6-1. 端末のOS自動バックアップに含まれます

記録データと写真は、端末のOSが行う自動バックアップ(iCloud バックアップ / Android バックアップ)や、機種変更時の端末間転送に含まれます。これはOSの仕様によるものです。バックアップされたデータの取り扱いは、Apple 社および Google 社のプライバシーポリシーに従います。

これを望まない場合は、端末の設定から本アプリをバックアップの対象外にしてください。

なお、アプリロックのパスコード情報だけは、これらのバックアップから明示的に除外しています。

6-2. 地図をダウンロードした地域が、提供元のアクセスログに残る可能性があります

地図・標高データの取得は、国土地理院のサーバーへの通信です。そのため、利用者が閲覧またはダウンロードした地域を示す情報が、提供元のアクセスログに記録される可能性があります。当方はこのログを取得できません。

秘匿性を重視する場合は、目的地よりも広い範囲をまとめてダウンロードする、通信できる場所であらかじめダウンロードしておく、といった運用が有効です。

6-3. 書き出したバックアップファイルは暗号化されていません

バックアップの書き出しで作成されるZIPファイルは、パスワードによる保護や暗号化を行っていません。また、このファイルには、アプリの画面には表示されない内部データ(初回記録時の座標、位置情報の精度の値)も含まれます。

書き出したファイルをどこに保存し、誰に渡すかは利用者の操作によって決まります。当方はその保存先を指定せず、関与しません。クラウドストレージや他のアプリへ渡した場合、そのデータの取り扱いは渡した先のサービスに従います。取り扱いには十分ご注意ください。

6-4. 記録の下書きが端末内に一時保存されます

記録の入力中にアプリが終了した場合に備え、入力途中の内容(座標を含む)を端末内に一時的に保存します。この情報は端末の外には出ません。保存が完了するか、入力を取りやめると削除されます。

7. 当方が行わないこと

  • 利用状況の解析(アナリティクス)、利用統計の送信
  • クラッシュレポートの自動送信
  • 広告の表示、広告関連ライブラリの組み込み
  • アカウント登録、クラウド同期
  • SNSへの共有機能の提供
  • 記録データの第三者への提供、および第三者からの取得

8. 将来の機能について

今後、不具合の調査を目的としたクラッシュレポートの送信や、任意のご意見送信の機能を追加する可能性があります。その場合も、次の方針を守ります。

  • 利用者が明示的に「送る」と選んだときだけ送信します(初期状態は送信しません)
  • 送信内容に位置情報を含めません
  • 追加にあたっては、本ポリシーを改定してその内容をお知らせします

9. データの削除・開示等の請求について

端末内のデータは、本アプリを端末から削除することですべて消去されます。個々の記録の削除は、アプリ内のゴミ箱機能から行えます。

当方は利用者の記録データを保有していないため、開示・訂正・利用停止・削除のご請求に対して提供できるデータを持ちません。この点をあらかじめご了承ください。
